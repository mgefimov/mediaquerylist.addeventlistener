MediaQueryList.addEventListener polyfill — live demo

Rotate the device (portrait ↔ landscape) to fire the listeners below — this flips on every rotation regardless of screen size. (Toggling system Dark Mode also works if you swap the query to (prefers-color-scheme: dark).)

Four listeners are registered, demonstrating the supported options: a plain function, an object with handleEvent, one added with { once: true } (fires only on the first change, then auto-removes), and one added with { signal } (fires until you abort it).
